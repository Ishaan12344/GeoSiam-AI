ConvNeXt-Tiny Siamese Dual-Stream U-Net

Pre- and Post-Disaster Building Damage Assessment — Honors Project (2026–2027)

1. Shared Siamese Encoder

ConvNeXt-Tiny Backbone

Extracts multi-scale hierarchical features at 4 resolutions ([96, 192, 384, 768] channels) with 7×7 depthwise convolutions from both pre- and post-disaster imagery using shared weights.

2. Localization Head

Building Footprint Decoder

Segments exact building polygons from pre-disaster imagery using transposed convolutions and skip connections, trained with Joint Dice + Binary Cross-Entropy Loss.

3. Bi-Temporal Fusion Head

4-Class Damage Classifier

Computes absolute feature difference |F_pre − F_post| concatenated with pre and post features at every scale. Trained with class-weighted Focal Loss (γ=2.0) to handle severe class imbalance.
